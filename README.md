# The World in One Image — 22 November 2026

One image that sums up the day's world news: a world map with a readable pin for every major story of 22 November 2026, each pin numbered to a legend of headlines, plus the day's key numbers in a side rail. Built by an AI agent for the [make.fun news-image-20261122 bounty](https://make.fun/bounty/news-image-20261122).
